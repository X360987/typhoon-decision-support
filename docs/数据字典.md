# 数据字典（节选）

所有业务查询应带 `dataset_id`、`event_id`。原始载荷使用 MySQL JSON。

## dataset

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 主键，如 `demo` |
| data_mode | string | `demo` / `real` |
| name | string | 显示名 |

## event

| 字段 | 说明 |
|------|------|
| event_code | 事件编号（数据集内唯一） |
| external_typhoon_id | 外部台风编号 |
| start_time / end_time | 分析窗口 |
| status | `tracking` / `historical` |
| config_version | 配置版本 |

## weibo_raw / weibo_clean

原始字段覆盖需求中的微博列；`stage` 若为事后生成不得作为当时特征。清洗后含 `account_class`、`sentiment_*`、`hour_bj`。未知情绪不计入负面比例分母。

## weibo_region

一条微博可对应多省；保留唯一记录与省份关联。未知区域不强行分配。

## train_suspension / train_stop / suspension_region_hour

停运与时刻表关联后映射到省份×小时；跨午夜按站序时间推进。

## province_hour_metric

唯一键：`dataset_id, event_id, province_code, hour_bj, metric_id, version`。`value` 允许 NULL（缺失不当零）。

## anomaly

| 字段 | 说明 |
|------|------|
| analysis_scope | `single` / `pair` / `joint` |
| dimensions | JSON 数组 |
| nature | `observation` / `prediction` |
| group_key | 去重分组 |
| rule_version | 规则版本 |

## forecast_snapshot / forecast_point

区分 `issued_at`、`arrived_at`、`valid_time`。回测只用起点当时已到达信息。

## prediction_result

按目标返回 `status`：`demo_ml_prediction` / `ml_prediction` / `baseline_prediction` / `insufficient_data` 等。
