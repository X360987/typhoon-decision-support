# 扩展说明

## 新增指标

1. 在 `app/services/metrics_registry.py` 的 `DEFAULT_METRICS` 增加条目（或写入 `metric_registry` 表）
2. 在 `app/services/pipeline.py` 的 `aggregate_metrics` 中按同一口径聚合
3. API `/metrics/registry` 与 `/metrics/series` 自动可见；前端卡片可按需引用

示例：已注册扩展指标 `help_request_count`（求助量）。

## 新增数据源

实现 `DataSourceAdapter`（见 `app/adapters/base.py`），复用 `import_service` 校验与入库；不要在前端写死数组。

## 替换情感模型

实现 `SentimentModel` 协议（`classify(text) -> SentimentResult`），在 `get_sentiment_model()` 中切换。保持标签契约：`negative|neutral|positive|unknown`，未知不进分母。

## 外部预报

实现 `ForecastProvider`，配置 URL/鉴权/频率。无可用接口时不得虚构已联网接入。保存快照字段：`issued_at`、`arrived_at`、`valid_time`、修订版本。

## 预测目标口径变更

修改 `config/prediction_targets.yaml` 的名称、单位、聚合方式后，须同步 API、页面、评估与导出文案，禁止静默改口径。
